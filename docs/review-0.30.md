# بازبینی امنیت و کارایی — نسخه ۰.۳۰.۰

تاریخ: ۲۰۲۶-۱۱-۱۴

## امنیت

| بخش | روش بررسی | نتیجه |
| --- | --- | --- |
| دسترسی REST | آزمون خودکار همه ۱۲۲ مسیر/متد با مهمان، مشترک، نویسنده و ویرایشگر | هیچ مسیر نوشتنی برای غیرمدیر باز نیست؛ ویرایشگر فقط خواندن دارد (به‌جز تنظیمات شخصی خودش: حالت ساده/حرفه‌ای و راهنماها) |
| نشت داده | فراخوانی همه مسیرهای GET با کلید آزمایشی کاشته‌شده | کلید هوش مصنوعی و ایمیل کاربران در هیچ پاسخی نیست؛ کلید فقط با ۴ نویسه آخر نمایش داده می‌شود |
| SQL | PHPCS (WordPress.DB) و بازبینی دستی همه پرس‌وجوهای بدون prepare | ورودی کاربر همیشه با prepare یا فهرست مجاز (orderby/order) است؛ بقیه فقط نام جدول یا شناسه‌های عددی |
| خروجی HTML | PHPCS (EscapeOutput) و بازبینی متاباکس، ابزارک پیشخوان، FAQ | همه خروجی‌ها escape شده‌اند؛ JSON-LD با JSON_HEX_TAG؛ موارد گزارش‌شده پیام استثنا هستند و در JSON برمی‌گردند |
| React | جست‌وجوی dangerouslySetInnerHTML و eval | استفاده نشده |
| فایل‌های بارگذاری | سقف حجم، بررسی is_uploaded_file، محدودیت zip (۵۰ فایل، ۲۰ مگابایت هر فایل) | درست |
| محتوای هوش مصنوعی | wp_kses_post و حذف بلوک‌های اجرایی پیش از ذخیره | درست |
| CSV | **اصلاح شد**: خانه‌هایی که با = + - @ شروع می‌شوند با ' آغاز می‌شوند (CSV injection) | |
| درخواست‌های بیرونی | لینک خارجی با wp_safe_remote_*؛ بسته به‌روزرسانی فقط https | **اصلاح شد**: بررسی ریدایرکت فقط میزبان همین سایت را درخواست می‌کند |
| ریدایرکت سایت | wp_safe_redirect | فقط مقصدهای مجاز |

## کارایی

| مورد | پیش از | پس از |
| --- | --- | --- |
| جاوااسکریپت بار اول پنل | ۳۵۷ کیلوبایت | ۱۲۲ کیلوبایت (پوسته + بخش مشترک)؛ هر صفحه ۳ تا ۴۰ کیلوبایت هنگام باز شدن |
| پیشنهاد صفحات کلیدی (۱۵۰۰ مطلب) | ۵۵۸ پرس‌وجو، ۱۳۴ میلی‌ثانیه | ۱۴ پرس‌وجو، ۴۵ میلی‌ثانیه |
| برنامه آدرس‌ها در کارهای هفته (۱۵۰۰ مطلب) | ۳۵۳ میلی‌ثانیه | ۱۳ میلی‌ثانیه |
| پیشخوان وردپرس | ۴ بار خواندن آخرین ورود سرچ کنسول | ۱ بار |
| هر صفحه مدیریت | پرس‌وجوی Action Scheduler برای کار روزانه | دو بار در روز |
| صفحات عمومی سایت | ۰ پرس‌وجو (صفحه ۴۰۴: ۱ پرس‌وجوی ریدایرکت) | بدون تغییر |

کندترین مسیرهای REST روی سایت ۱۵۰۰ مطلبی: کارهای هفته ۱۱۸، روند بهبود ۷۵ میلی‌ثانیه.

## سازگاری

- PHP 8.5/8.6: نام ثابت NAMESPACE (کلمه رزرو) به REST_NAMESPACE تغییر کرد؛ imagedestroy حذف شد؛ پارامتر escape در fputcsv صریح شد.
- هشدارهای «trim و form feed» در PHP 8.6 اثری بر رفتار ندارند.

## باقی‌مانده برای ۰.۳۱ تا ۱.۰

- آزمون واحد بیشتر برای برنامه‌های بهبود (برچسب، آدرس، مقاله، لینک).
- دسترس‌پذیری پنل (صفحه‌کلید، برچسب‌ها، کنتراست).
- فایل ترجمه و آماده‌سازی انتشار؛ اطلاعات پشتیبانی و لایسنس در مرحله نهایی.
